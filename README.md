# Система сбора и анализа статистики устройств

Асинхронный REST-сервис на **FastAPI** для приёма, хранения и фонового анализа временных рядов данных (x, y, z) от множества устройств.  
Вычисления статистики (min, max, count, sum, median) вынесены в **Celery** с брокером **Redis**, что позволяет не блокировать основной API.

## Стек технологий

- Python 3.10
- FastAPI + Uvicorn
- PostgreSQL (SQLAlchemy ORM, async/синхронный режимы)
- Celery + Redis (брокер и бэкенд)
- Docker / Docker Compose
- Locust (нагрузочное тестирование)

## Функциональные возможности

- **Сбор данных** `POST /devices/{device_id}/data` – приём трёх float-значений, автоматическое создание устройства.
- **Асинхронная статистика устройства** `POST /devices/{device_id}/stats` – возвращает `task_id`, вычисления в фоне.
- **Статистика пользователя** `POST /users/{user_id}/stats` – агрегированные данные по всем устройствам пользователя + отдельно по каждому устройству.
- **Управление пользователями** – создание пользователя, привязка устройств.
- **Получение результата** `GET /tasks/{task_id}` – опрос готовности задачи.
